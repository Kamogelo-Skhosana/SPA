# Demo evidence checklist

- [ ] Overview screenshot shows XRPL Testnet and simulated values clearly.
- [ ] Mandate screenshot shows cap, total budget, suppliers, expiry, and active status.
- [ ] Approved request trace shows extracted fields, policy checks, and explicit operator confirmation.
- [ ] Real settlement evidence includes testnet network, transaction hash, explorer URL, validated result, ledger index, amount, currency, issuer, destination, and timestamp.
- [ ] Protected request trace shows the exact failed rule and no signing or submission event.
- [ ] Refresh and retry show a consistent request status without duplicate payment.
- [ ] Setup screen distinguishes fixture progress from actual wallet/trustline state.
- [ ] Mobile and desktop screenshots show usable navigation and readable status.
- [ ] Demo recording follows the timed script and labels each simulation.

Attach only evidence captured from the running implementation. Never use placeholder addresses in a transaction or present fixture outcomes as ledger confirmations.
